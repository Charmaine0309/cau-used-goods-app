# 举报模块接口测试说明

## 1. 测试目标

验证举报模块接口功能是否正常，包括提交举报、查看举报列表、管理员处理举报等操作，以及边界和异常场景处理。

## 2. 测试环境

- 后端服务：`http://127.0.0.1:8080`
- 测试日期：2026-06-09
- 测试人员：尹双雨

## 3. 正常场景测试用例

### TC-RPT-001: 正常提交举报

```bash
curl -X POST http://127.0.0.1:8080/reports \
  -H "Authorization: Bearer <buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"targetType":"PRODUCT","targetId":1,"reasonType":"FAKE","description":"test report"}'
```

**预期结果：** code=0, status=PENDING

**实际结果：** PASS

## 4. 异常场景测试用例

```bash

  -H "Content-Type: application/json" \
  -d '{"targetType":"PRODUCT","targetId":1,"reasonType":"FAKE"}'
```

**预期结果：** code=401, message=unauthorized

**实际结果：** PASS

### TC-RPT-011: 重复举报同一目标

```bash
curl -X POST http://127.0.0.1:8080/reports \
  -H "Authorization: Bearer <buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"targetType":"PRODUCT","targetId":1,"reasonType":"FAKE"}'
```

前置条件：该用户对该商品已有待处理举报

**预期结果：** code=400, message 提示重复举报

**实际结果：** PASS
