# 管理员处理举报接口

## 1. 接口信息

```http
POST /admin/reports/:id/handle
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

管理员处理举报，将举报状态设置为 `APPROVED`（举报成立）或 `REJECTED`（已驳回）。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 举报 ID |

## 3. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `status` | string | 是 | APPROVED / REJECTED | 处理结果 |
| `handleResult` | string | 否 | 最长 1000 字符 | 处理说明 |

请求示例：

```json
{
  "status": "APPROVED",
  "handleResult": "经核实，商品描述确实与实际不符，举报成立。已下架该商品。"
}
```

## 4. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "status": "APPROVED",
    "handleResult": "经核实，商品描述确实与实际不符，举报成立。已下架该商品。",
    "handlerId": 4,
    "handleTime": "2026-06-09T13:00:00+08:00",
    "updateTime": "2026-06-09T13:00:00+08:00"
  },
  "timestamp": "2026-06-09 13:00:00"
}
```

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `status` | 400 | 400 | invalid request body |
| `status` 非法 | 400 | 400 | 必须为 APPROVED/REJECTED |
| 传入 `accountStatus` | 400 | 400 | accountStatus is deprecated |
| 非管理员 | 403 | 403 | permission denied |
| 未登录 | 401 | 401 | unauthorized |
