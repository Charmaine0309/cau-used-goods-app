# 提交举报接口

## 1. 接口信息

```http
POST /reports
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

用户提交举报，举报类型包括商品、用户、订单。

## 2. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `targetType` | string | 是 | PRODUCT / USER / ORDER | 举报目标类型 |
| `targetId` | uint64 | 是 | 大于 0 | 举报目标 ID |
| `reasonType` | string | 是 | 预定义原因类型 | 举报原因类型 |
| `description` | string | 否 | 最长 2000 字符 | 详细描述 |
| `images` | string[] | 否 | 最多 9 张 | 凭证图片 URL 列表 |

请求示例：

```json
{
  "targetType": "PRODUCT",
  "targetId": 1,
  "reasonType": "FAKE_PRODUCT",
  "description": "商品描述与实际严重不符",
  "images": [
    "/uploads/reports/1_1.jpg",
    "/uploads/reports/1_2.jpg"
  ]
}
```

## 3. 响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "reporterId": 2,
    "targetType": "PRODUCT",
    "targetId": 1,
    "reasonType": "FAKE_PRODUCT",
    "description": "商品描述与实际严重不符",
    "status": "PENDING",
    "images": [
      "/uploads/reports/1_1.jpg",
      "/uploads/reports/1_2.jpg"
    ],
    "createTime": "2026-06-09T12:00:00+08:00",
    "updateTime": "2026-06-09T12:00:00+08:00"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少必填字段 | 400 | 400 | invalid request body |
| `targetType` 非法 | 400 | 400 | 必须为 PRODUCT/USER/ORDER |
| 重复举报同一目标 | 400 | 400 | you have already reported this target |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
