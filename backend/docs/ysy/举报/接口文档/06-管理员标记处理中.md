# 管理员标记举报处理中接口

## 1. 接口信息

```http
POST /admin/reports/:id/processing
Authorization: Bearer jwt_access_token
```

管理员将举报状态从 `PENDING` 标记为 `PROCESSING`。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 举报 ID |

## 3. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "status": "PROCESSING",
    "handlerId": 4,
    "updateTime": "2026-06-09T12:30:00+08:00"
  },
  "timestamp": "2026-06-09 12:30:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 举报不存在 | 400 | 400 | report not found |
| 非管理员 | 403 | 403 | permission denied |
| 未登录 | 401 | 401 | unauthorized |
