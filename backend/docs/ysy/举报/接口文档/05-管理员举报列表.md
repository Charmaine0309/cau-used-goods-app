# 管理员举报列表接口

## 1. 接口信息

```http
GET /admin/reports?status=PENDING&page=1&pageSize=20
Authorization: Bearer jwt_access_token
```

管理员查看所有举报列表，支持按状态筛选。

## 2. 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `status` | string | 否 | 空 | 筛选状态：PENDING / PROCESSING / APPROVED / REJECTED / CLOSED |
| `page` | int | 否 | 1 | 页码 |
| `pageSize` | int | 否 | 20 | 每页数量 |

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 非管理员 | 403 | 403 | permission denied |
| 未登录 | 401 | 401 | unauthorized |
