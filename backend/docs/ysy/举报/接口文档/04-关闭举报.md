# 关闭举报接口

## 1. 接口信息

```http
POST /reports/:id/close
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

举报人主动关闭举报。关闭后举报状态变为 `CLOSED`。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 举报 ID |

## 3. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `closeReason` | string | 否 | 最长 500 字符 | 关闭原因 |

请求示例：

```json
{
  "closeReason": "已与卖家协商解决"
}
```

## 4. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "status": "CLOSED",
    "closeReason": "已与卖家协商解决"
  },
  "timestamp": "2026-06-09 14:00:00"
}
```

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 非本人举报 | 403 | 403 | permission denied |
| 举报不存在 | 404 | 404 | report not found |
| 举报状态不允许关闭 | 400 | 400 | report cannot be closed |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
