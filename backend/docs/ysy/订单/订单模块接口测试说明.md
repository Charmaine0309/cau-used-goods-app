# 订单模块接口测试说明

## 1. 测试目标

验证订单模块接口功能是否正常，包括创建订单、查看订单、确认订单、完成订单、取消订单等操作，以及订单状态流转和异常场景处理。

## 2. 测试环境

- 后端服务：`http://127.0.0.1:8080`
- 测试日期：2026-06-09
- 测试人员：尹双雨

## 3. 正常场景测试用例

### TC-ORD-001: 正常创建订单

```bash
curl -X POST http://127.0.0.1:8080/orders \
  -H "Authorization: Bearer <buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"productId":1,"remark":"test order","meetLocation":"lib"}'
```

**预期结果：** code=0, status=PENDING_CONFIRM, orderNo 生成正确

**实际结果：** PASS

## 4. 异常场景测试用例

### TC-ORD-013: 未登录创建订单

```bash
curl -X POST http://127.0.0.1:8080/orders \
  -H "Content-Type: application/json" \
  -d '{"productId":1}'
```

**预期结果：** code=401, message=unauthorized

**实际结果：** PASS

### TC-ORD-014: 重复预约同一商品

```bash
curl -X POST http://127.0.0.1:8080/orders \
  -H "Authorization: Bearer <buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"productId":1}'
```

前置条件：该用户对该商品已有进行中订单

**预期结果：** code=400, message 提示已有进行中的订单

**实际结果：** PASS

### TC-ORD-016: 商品已被锁定/售出

```bash
curl -X POST http://127.0.0.1:8080/orders \
  -H "Authorization: Bearer <other_buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"productId":1}'
```

前置条件：商品状态为 LOCKED 或 SOLD

**预期结果：** code=400, message 提示商品不可用

**实际结果：** PASS

### TC-ORD-017: 非卖家确认订单

```bash
  -H "Authorization: Bearer <buyer_token>"
```

**预期结果：** code=400 或 403, message 提示无权操作

**实际结果：** PASS
