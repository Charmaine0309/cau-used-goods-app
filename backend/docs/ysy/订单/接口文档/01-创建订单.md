# 创建订单接口

## 1. 接口信息

```http
POST /orders
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

买家创建订单，预约购买指定商品。创建订单时会同时锁定商品状态为 `LOCKED`。

## 2. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `productId` | uint64 | 是 | 大于 0 | 要购买的商品 ID |
| `remark` | string | 否 | 最长 500 字符 | 买家备注 |
| `meetTime` | string | 否 | 时间格式 | 约定见面时间 |
| `meetLocation` | string | 否 | 最长 200 字符 | 约定见面地点 |

请求示例：

```json
{
  "productId": 1,
  "remark": "希望明天下午交易",
  "meetTime": "2026-06-10T14:00:00+08:00",
  "meetLocation": "图书馆门口"
}
```

## 3. 响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "orderNo": "O20260609123456000100",
    "productId": 1,
    "buyerId": 2,
    "sellerId": 3,
    "productTitleSnapshot": "二手自行车",
    "productPriceSnapshot": 100.00,
    "status": "PENDING_CONFIRM",
    "remark": "希望明天下午交易",
    "meetLocation": "图书馆门口",
    "expireTime": "2026-06-10T12:00:00+08:00",
    "createTime": "2026-06-09T12:00:00+08:00"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `productId` | 400 | 400 | 参数绑定失败 |
| 购买自己的商品 | 400 | 400 | cannot buy your own product |
| 重复预约同一商品 | 400 | 400 | you already have an active order for this product |
| 商品已被锁定/售出 | 400 | 400 | product not available |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
