# 我的订单列表接口

## 1. 接口信息

```http
GET /orders?role=buyer&status=&page=1&pageSize=20
Authorization: Bearer jwt_access_token
```

获取当前登录用户的订单列表，支持按角色（买家/卖家）和状态筛选。

## 2. 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `role` | string | 否 | buyer | buyer（我买的）/ seller（我卖的）|
| `status` | string | 否 | 空 | 筛选状态：PENDING_CONFIRM / WAIT_MEET / COMPLETED / CANCELED / EXCEPTION_CLOSED |
| `page` | int | 否 | 1 | 页码 |
| `pageSize` | int | 否 | 20 | 每页数量 |
