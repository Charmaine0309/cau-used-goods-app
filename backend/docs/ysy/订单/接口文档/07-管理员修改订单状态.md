# 管理员修改订单状态接口

## 1. 接口信息

```http
PUT /admin/orders/:id/status
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

管理员修改订单状态。不能将状态修改为 `EXCEPTION_CLOSED`，必须使用异常关闭接口。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 订单 ID |

## 3. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `status` | string | 是 | PENDING_CONFIRM / WAIT_MEET / COMPLETED / CANCELED | 目标状态 |
| `reason` | string | 否 | 最长 500 字符 | 修改原因 |
| `relatedType` | string | 否 | REPORT / APPEAL | 关联来源类型 |
| `relatedId` | uint64 | 否 | 大于 0 | 关联来源 ID |

`relatedType` 和 `relatedId` 必须同时传或同时不传。

请求示例：

```json
{
  "status": "CANCELED",
  "reason": "举报成立，取消订单",
  "relatedType": "REPORT",
  "relatedId": 123
}
```

## 4. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "status": "CANCELED"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `status` | 400 | 400 | invalid request body |
| 状态为 EXCEPTION_CLOSED | 400 | 400 | 必须使用异常关闭接口 |
| 非管理员 | 403 | 403 | permission denied |
| 未登录 | 401 | 401 | unauthorized |
