# 管理员异常关闭订单接口

## 1. 接口信息

```http
POST /admin/orders/:id/exception-close
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

管理员异常关闭订单。需要指定责任方，用于交易过程中出现特殊情况（如商品损坏、卖家无法履约等）。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 订单 ID |

## 3. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `reason` | string | 是 | 不能为空 | 关闭原因 |
| `responsibleParty` | string | 是 | BUYER / SELLER | 责任方 |
| `relatedType` | string | 否 | REPORT / APPEAL | 关联来源类型 |
| `relatedId` | uint64 | 否 | 大于 0 | 关联来源 ID |

请求示例：

```json
{
  "reason": "举报成立，管理员异常关闭订单",
  "responsibleParty": "SELLER",
  "relatedType": "REPORT",
  "relatedId": 123
}
```

## 4. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "status": "EXCEPTION_CLOSED",
    "reason": "举报成立，管理员异常关闭订单",
    "responsibleParty": "SELLER"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `reason` 或 `responsibleParty` | 400 | 400 | reason and responsibleParty are required |
| 订单状态不允许异常关闭 | 400 | 400 | order cannot be exception closed |
| 非管理员 | 403 | 403 | permission denied |
| 未登录 | 401 | 401 | unauthorized |
