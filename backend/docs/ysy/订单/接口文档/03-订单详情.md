# 订单详情接口

## 1. 接口信息

```http
GET /orders/:id
Authorization: Bearer jwt_access_token
```

获取指定订单的详细信息。只有订单的买卖双方可以查看。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 订单 ID |

## 3. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "orderNo": "O20260609123456000100",
    "productId": 1,
    "productTitleSnapshot": "二手自行车",
    "productPriceSnapshot": 100.00,
    "buyerId": 2,
    "sellerId": 3,
    "status": "PENDING_CONFIRM",
    "remark": "希望明天下午交易",
    "meetLocation": "图书馆门口",
    "expireTime": "2026-06-10T12:00:00+08:00",
    "createTime": "2026-06-09T12:00:00+08:00",
    "updateTime": "2026-06-09T12:00:00+08:00"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 订单不存在 | 404 | 404 | order not found |
| 非买卖双方访问 | 403 | 403 | permission denied |
| 未登录 | 401 | 401 | unauthorized |
