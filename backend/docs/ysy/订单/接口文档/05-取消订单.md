# 取消订单接口

## 1. 接口信息

```http
POST /orders/:id/cancel
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

买家或卖家取消订单。取消后商品状态恢复为 `ON_SALE`。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 订单 ID |

## 3. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `reason` | string | 是 | 不能为空 | 取消原因 |

请求示例：

```json
{
  "reason": "临时有事，无法交易"
}
```

## 4. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "status": "CANCELED",
    "cancelReason": "临时有事，无法交易",
    "closeTime": "2026-06-09T13:00:00+08:00"
  },
  "timestamp": "2026-06-09 13:00:00"
}
```

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `reason` | 400 | 400 | cancel reason is required |
| 非买卖双方取消 | 400 | 400 | permission denied |
| 订单状态不允许取消 | 400 | 400 | order cannot be cancelled |
| 订单不存在 | 404 | 404 | order not found |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
