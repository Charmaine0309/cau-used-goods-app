# 完成订单接口

## 1. 接口信息

```http
POST /orders/:id/complete
Authorization: Bearer jwt_access_token
```

卖家确认交易完成，订单状态从 `WAIT_MEET` 变为 `COMPLETED`，商品状态变为 `SOLD`。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 订单 ID |

## 3. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "status": "COMPLETED",
    "finishTime": "2026-06-09T15:00:00+08:00"
  },
  "timestamp": "2026-06-09 15:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 非卖家完成 | 400 | 400 | permission denied |
| 订单状态不允许完成 | 400 | 400 | order cannot be completed |
| 订单不存在 | 404 | 404 | order not found |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
