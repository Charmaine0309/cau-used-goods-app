# 评价模块接口测试说明

## 1. 测试目标

验证评价模块接口功能是否正常，包括提交评价、查看评价详情、商品评价列表、卖家评价列表等操作，以及边界和异常场景处理。

## 2. 测试环境

- 后端服务：`http://127.0.0.1:8080`
- 测试日期：2026-06-09
- 测试人员：尹双雨

## 3. 正常场景测试用例

### TC-REV-001: 正常提交评价

```bash
curl -X POST http://127.0.0.1:8080/reviews \
  -H "Authorization: Bearer <buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"orderId":1,"rating":5,"content":"great product"}'
```

**预期结果：** code=0, rating=5, 数据正确

**实际结果：** PASS

### TC-REV-002: 查看商品评价列表（公开接口）

```bash
curl "http://127.0.0.1:8080/products/1/reviews?page=1&pageSize=10"
```

**预期结果：** code=0, total>=1, 无需登录

**实际结果：** PASS

### TC-REV-003: 查看卖家评价列表（公开接口）

```bash

```

**预期结果：** code=0, avgRating>0, reviewCount>0

**实际结果：** PASS

### TC-REV-004: 查看评价详情（公开接口）

```bash

```

**预期结果：** code=0, 数据完整

## 4. 异常场景测试用例

### TC-REV-006: 未登录提交评价

```bash
curl -X POST http://127.0.0.1:8080/reviews \
  -H "Content-Type: application/json" \
  -d '{"orderId":1,"rating":5}'
```

**预期结果：** code=401, message=unauthorized

**实际结果：** PASS

### TC-REV-007: 评价未完成的订单

```bash
curl -X POST http://127.0.0.1:8080/reviews \
  -H "Authorization: Bearer <buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"orderId":3,"rating":5}'
```

前置条件：订单状态为 PENDING_CONFIRM 或 WAIT_MEET

**预期结果：** code=400, message 提示订单未完成

**实际结果：** PASS

### TC-REV-008: 重复评价同一订单

```bash
curl -X POST http://127.0.0.1:8080/reviews \
  -H "Authorization: Bearer <buyer_token>" \
  -H "Content-Type: application/json" \
  -d '{"orderId":1,"rating":4}'
```

前置条件：该订单已评价过

**预期结果：** code=400, message 提示已评价

**实际结果：** PASS

### TC-REV-009: 非买家评价订单

```bash
curl -X POST http://127.0.0.1:8080/reviews \
  -H "Authorization: Bearer <seller_token>" \
  -H "Content-Type: application/json" \
  -d '{"orderId":1,"rating":5}'
```

前置条件：使用卖家 token 评价买家的订单

**预期结果：** code=400 或 403, message 提示无权评价

**实际结果：** PASS
