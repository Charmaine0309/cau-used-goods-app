# 评价模块开发说明

## 1. 模块概述

评价模块负责处理交易完成后的评价功能，包括提交评价、查看评价详情、商品评价列表、卖家评价列表及卖家评分统计等。

## 2. 开发思路

### 2.1 评价规则

- 只有买家可以评价
- 只有已完成的订单才能评价
- 一个订单只能评价一次
- 评分范围 1-5 星
- 评价内容可选

### 2.2 评分统计

- 卖家评价列表接口实时计算平均分（`avgRating`）和评价总数（`reviewCount`）
- 便于前端展示卖家信誉

### 2.3 公开接口设计

- 商品评价列表、卖家评价列表、评价详情为公开接口，无需登录
- 便于未登录用户浏览商品时查看评价

## 3. 接口清单

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/reviews` | 提交评价 | 登录+认证 |
| GET | `/reviews/:id` | 评价详情 | 公开 |
| GET | `/products/:id/reviews` | 商品评价列表 | 公开 |
| GET | `/sellers/:id/reviews` | 卖家评价列表 | 公开 |

## 4. 测试情况

- 提交评价测试通过
- 商品/卖家评价列表查询测试通过
- 平均分统计正确

## 5. 注意事项

- 提交评价时严格校验订单状态和买家身份
- 公开接口注意数据脱敏，不暴露敏感信息
