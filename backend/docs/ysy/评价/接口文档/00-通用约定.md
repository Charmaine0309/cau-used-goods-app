# 评价模块通用约定

## 1. Base URL

```text
http://127.0.0.1:8080
```

## 2. 鉴权

- 提交评价需要登录 + 学生认证 `VERIFIED`
- 查看评价列表和评价详情是公开接口，无需登录

需要登录的接口：

```http
Authorization: Bearer <token>
```

## 3. 统一响应

成功：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": "2026-06-09 12:00:00"
}
```

失败：

```json
{
  "code": 400,
  "message": "错误说明",
  "data": null,
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 分页约定

列表类接口使用：

| 参数 | 类型 | 默认 | 规则 |
| --- | --- | --- | --- |
| `page` | number | 1 | 小于 1 时按 1 处理 |
| `pageSize` | number | 20 | 小于 1 时按 20，最大 100 |

分页响应：

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "pageSize": 20
}
```

## 5. 模块职责

评价模块负责处理交易完成后的评价功能，包括提交评价、查看评价详情、商品评价列表、卖家评价列表及卖家评分统计等。

## 6. 关联数据表

- `reviews` — 评价表
- `orders` — 订单表（校验订单状态）
- `products` — 商品表（关联查询商品信息）

## 7. 核心规则

1. **只有买家可以评价**
2. **只有已完成的订单才能评价**
3. **一个订单只能评价一次**
4. 评分范围 1-5 星
5. 评价内容可选

## 8. 前端错误处理建议

- `401`：清理登录态并跳转登录页。
- `403`：展示权限或账号状态提示，不要重试。
- `400`：展示业务错误提示，如参数错误、订单未完成、重复评价等。
- `404`：评价或商品不存在。
- `500`：展示系统异常提示，并记录接口与请求参数方便排查。
