# 提交评价接口

## 1. 接口信息

```http
POST /reviews
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

买家对已完成订单提交评价。只有订单的买家才能评价，且订单状态必须为 `COMPLETED`。

## 2. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `orderId` | uint64 | 是 | 大于 0 | 订单 ID |
| `rating` | int | 是 | 1-5 | 评分（1-5 星）|
| `content` | string | 否 | 最长 1000 字符 | 评价内容 |

请求示例：

```json
{
  "orderId": 1,
  "rating": 5,
  "content": "商品和描述一致，卖家很靠谱！"
}
```

## 3. 响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "orderId": 1,
    "productId": 1,
    "reviewerId": 2,
    "sellerId": 3,
    "rating": 5,
    "content": "商品和描述一致，卖家很靠谱！",
    "status": "NORMAL",
    "createTime": "2026-06-09T15:30:00+08:00"
  },
  "timestamp": "2026-06-09 15:30:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `orderId` 或 `rating` | 400 | 400 | invalid request body |
| 评分超出 1-5 范围 | 400 | 400 | rating must be between 1 and 5 |
| 非买家评价 | 400 | 400 | only buyer can review |
| 订单未完成 | 400 | 400 | can only review completed orders |
| 重复评价 | 400 | 400 | you have already reviewed this order |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
