# 商品评价列表接口

## 1. 接口信息

```http
GET /products/:id/reviews?page=1&pageSize=20
```

获取指定商品的评价列表。公开接口，无需登录。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 商品 ID |

## 3. 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码 |
| `pageSize` | int | 否 | 20 | 每页数量 |

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 无效的商品 ID | 400 | 400 | invalid product id |
