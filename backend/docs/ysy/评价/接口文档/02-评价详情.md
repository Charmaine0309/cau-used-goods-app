# 评价详情接口

## 1. 接口信息

```http
GET /reviews/:id
```

获取指定评价的详细信息。公开接口，无需登录。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | uint64 | 评价 ID |

## 3. 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "orderId": 1,
    "productId": 1,
    "productTitle": "二手自行车",
    "reviewerId": 2,
    "reviewerNickname": "李四",
    "reviewerAvatar": "/uploads/avatar/2.jpg",
    "sellerId": 3,
    "rating": 5,
    "content": "商品和描述一致，卖家很靠谱！",
    "status": "NORMAL",
    "createTime": "2026-06-09T15:30:00+08:00"
  },
  "timestamp": "2026-06-09 15:30:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 评价不存在 | 404 | 404 | review not found |
| 无效的 `id` | 400 | 400 | invalid review id |
