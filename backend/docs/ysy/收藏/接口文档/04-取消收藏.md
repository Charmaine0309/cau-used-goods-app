# 取消收藏接口

## 1. 接口信息

```http
DELETE /favorites/:productId
Authorization: Bearer jwt_access_token
```

取消对指定商品的收藏。采用软删除方式，不是物理删除。

## 2. 路径参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `productId` | uint64 | 商品 ID |

## 3. 响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "favorited": false
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 无效的 `productId` | 400 | 400 | invalid product id |
| 未收藏该商品 | 400 | 400 | not favorited |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
