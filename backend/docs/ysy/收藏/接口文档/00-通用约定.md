# 收藏模块通用约定

## 1. Base URL

```text
http://127.0.0.1:8080
```

## 2. 鉴权

所有接口需要登录：

```http
Authorization: Bearer <token>
```

同时要求当前用户学生认证状态为 `VERIFIED`。

## 3. 统一响应

成功：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": "2026-06-09 12:00:00"
}
```

失败：

```json
{
  "code": 400,
  "message": "错误说明",
  "data": null,
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 分页约定

列表类接口使用：

| 参数 | 类型 | 默认 | 规则 |
| --- | --- | --- | --- |
| `page` | number | 1 | 小于 1 时按 1 处理 |
| `pageSize` | number | 20 | 小于 1 时按 20，最大 100 |

分页响应：

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "pageSize": 20
}
```

## 5. 模块职责

收藏模块负责处理用户对商品的收藏功能，包括收藏、取消收藏、查询收藏状态、获取收藏列表等操作。

## 6. 关联数据表

- `favorites` — 收藏表
- `products` — 商品表（关联查询商品信息）

## 7. 核心规则

1. 同一用户对同一商品只能收藏一次（唯一约束）
2. 取消收藏是软删除（`is_deleted = 1`），不是物理删除
3. 再次收藏同一商品会恢复之前的记录

## 8. 前端错误处理建议

- `401`：清理登录态并跳转登录页。
- `403`：展示权限或账号状态提示，不要重试。
- `400`：展示业务错误提示，如参数错误、重复收藏等。
- `500`：展示系统异常提示，并记录接口与请求参数方便排查。
