# 收藏商品接口

## 1. 接口信息

```http
POST /favorites
Content-Type: application/json
Authorization: Bearer jwt_access_token
```

用于收藏指定商品。同一用户对同一商品只能收藏一次。

## 2. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `productId` | uint64 | 是 | 大于 0 | 商品 ID |

请求示例：

```json
{
  "productId": 1
}
```

## 3. 响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "favorited": true
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `productId` | 400 | 400 | productId is required |
| 商品不存在 | 400 | 400 | 外键约束失败 |
| 重复收藏 | 400 | 400 | already favorited |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
