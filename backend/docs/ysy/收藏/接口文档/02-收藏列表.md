# 收藏列表接口

## 1. 接口信息

```http
GET /favorites?page=1&pageSize=20
Authorization: Bearer jwt_access_token
```

获取当前登录用户的收藏列表，支持分页。

## 2. 请求参数（Query）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码 |
| `pageSize` | int | 否 | 20 | 每页数量 |

## 3. 响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 1,
        "userId": 2,
        "productId": 1,
        "createTime": "2026-06-09T12:00:00+08:00",
        "isDeleted": false,
        "productTitle": "二手自行车",
        "productPrice": 200.00,
        "productStatus": "ON_SALE"
      }
    ],
    "total": 10,
    "page": 1,
    "pageSize": 20
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
