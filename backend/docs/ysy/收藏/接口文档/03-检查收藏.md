# 检查收藏状态接口

## 1. 接口信息

```http
GET /favorites/check?productId=1
Authorization: Bearer jwt_access_token
```

检查当前用户是否已收藏指定商品。

## 2. 请求参数（Query）

| 字段 | 类型 | 必填 | 规则 | 说明 |
|------|------|------|------|------|
| `productId` | uint64 | 是 | 大于 0 | 商品 ID |

## 3. 响应

成功响应：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "favorited": true
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 错误响应

| 场景 | HTTP | code | 说明 |
|------|------|------|------|
| 缺少 `productId` | 400 | 400 | invalid product id |
| 未登录 | 401 | 401 | unauthorized |
| 未学生认证 | 403 | 403 | student verification required |
