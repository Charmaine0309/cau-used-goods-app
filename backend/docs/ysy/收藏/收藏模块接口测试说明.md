# 收藏模块接口测试说明

## 1. 测试目标

验证收藏模块接口功能是否正常，包括收藏商品、查询收藏状态、获取收藏列表、取消收藏等操作，以及边界和异常场景处理。

## 2. 测试环境

- 后端服务：`http://127.0.0.1:8080`
- 测试日期：2026-06-09
- 测试人员：尹双雨

## 3. 正常场景测试用例

### TC-FAV-001: 正常收藏商品

```bash
curl -X POST http://127.0.0.1:8080/favorites \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"productId":1}'
```

**预期结果：** code=0, data.favorited=true

**实际结果：** PASS

### TC-FAV-002: 检查收藏状态

```bash
curl "http://127.0.0.1:8080/favorites/check?productId=1" \
  -H "Authorization: Bearer <token>"
```

**预期结果：** code=0, data.favorited=true

**实际结果：** PASS

### TC-FAV-003: 获取收藏列表

```bash
curl "http://127.0.0.1:8080/favorites?page=1&pageSize=10" \
  -H "Authorization: Bearer <token>"
```

**预期结果：** code=0, data.items 不为空

**实际结果：** PASS

### TC-FAV-004: 取消收藏

```bash
curl -X DELETE "http://127.0.0.1:8080/favorites/1" \
  -H "Authorization: Bearer <token>"
```

**预期结果：** code=0, data.favorited=false

**实际结果：** PASS

### TC-FAV-005: 重新收藏已取消的商品（恢复记录）

```bash

  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"productId":1}'
```

**预期结果：** code=0, data.favorited=true（恢复之前的记录，不是新增）

**实际结果：** PASS
