# 收藏模块开发说明

## 1. 模块概述

收藏模块负责处理用户对商品的收藏功能，包括收藏、取消收藏、查询收藏状态、获取收藏列表等操作。

## 2. 开发思路

### 2.1 数据库设计

- `favorites` 表：记录用户与商品的收藏关系
- 采用软删除（`is_deleted`），不是物理删除
- 同一用户对同一商品只能收藏一次（唯一约束）

### 2.2 核心逻辑

- 收藏商品时，检查是否已存在记录
  - 不存在：新增记录
  - 已存在且已删除：恢复记录（`is_deleted = false`）
  - 已存在且未删除：返回重复收藏错误
- 取消收藏时，软删除记录（`is_deleted = true`）

### 2.3 关联查询

- 收藏列表接口关联 `products` 表，返回商品标题、价格、状态等信息
- 便于前端直接展示收藏商品列表，无需二次查询

## 3. 接口清单

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | `/favorites` | 收藏商品 | 登录+认证 |
| GET | `/favorites` | 收藏列表 | 登录+认证 |
| GET | `/favorites/check` | 检查是否收藏 | 登录+认证 |
| DELETE | `/favorites/:productId` | 取消收藏 | 登录+认证 |

## 4. 测试情况

- 收藏、查询、取消流程测试通过
- 重复收藏边界测试通过

## 5. 注意事项

- 收藏列表接口需要关联商品表，注意性能优化
- 商品下架后，收藏记录仍保留，前端需根据 `productStatus` 判断展示
