# 开发环境登录接口

## 1. 接口信息

```http
POST /auth/dev-login
Content-Type: application/json
```

仅当 `config/config.yaml` 中 `server.env=dev` 时注册。非 dev 环境访问该路径会得到路由不存在。

该接口用于本地联调，不调用微信接口。

## 2. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
| --- | --- | --- | --- | --- |
| `openid` | string | 否 | trim 后最长 64 字符 | 模拟微信 openid；空值默认 `dev_openid_001` |
| `role` | string | 否 | 只能为 `USER` 或 `ADMIN` | 调整当前测试账号角色；空值保持原角色 |

普通用户示例：

```json
{
  "openid": "dev_user_001",
  "role": "USER"
}
```

管理员示例：

```json
{
  "openid": "dev_admin_001",
  "role": "ADMIN"
}
```

## 3. 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "jwt_access_token",
    "user": {
      "id": 2,
      "nickname": null,
      "avatarUrl": null,
      "role": "ADMIN",
      "authStatus": "UNVERIFIED",
      "accountStatus": "NORMAL"
    }
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 业务规则

- openid 不存在时创建新用户。
- 新用户默认 `role=USER`、`authStatus=UNVERIFIED`、`accountStatus=NORMAL`。
- 如果传入 `role` 且账号未注销，后端会更新用户角色并重新签发 token。
- `role` 不能设置为 `SUPER_ADMIN`。
- 如果账号已注销，返回恢复分支，行为与微信登录一致。

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
| --- | ---: | ---: | --- |
| JSON 格式错误 | 400 | 400 | 请求体不是合法 JSON |
| `openid` 超过 64 字符 | 400 | 400 | 长度校验失败 |
| `role` 不是 `USER` / `ADMIN` | 400 | 400 | 枚举校验失败 |
| 非 dev 环境访问 | 404 | - | 路由未注册，由 Gin 返回 |

前端联调建议：开发环境可以用不同 openid 固定模拟不同账号，避免多人共用默认 `dev_openid_001` 导致角色互相覆盖。
