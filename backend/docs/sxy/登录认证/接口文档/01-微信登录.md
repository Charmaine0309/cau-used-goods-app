# 微信登录接口

## 1. 接口信息

```http
POST /auth/wechat-login
Content-Type: application/json
```

用于微信小程序登录。前端先调用 `wx.login` 获取临时 `code`，再把 `code` 传给后端。后端使用微信 `jscode2session` 换取 `openid`，再查询或创建本平台用户。

## 2. 请求参数

| 字段 | 类型 | 必填 | 规则 | 说明 |
| --- | --- | --- | --- | --- |
| `code` | string | 是 | trim 后不能为空，最长 128 字符 | `wx.login` 返回的临时登录凭证 |

请求示例：

```json
{
  "code": "0f3Sxxxxxxxxxxxx"
}
```

## 3. 正常登录响应

当 openid 对应用户不存在时，后端会创建新用户；当用户存在且未注销时，后端更新 `last_login_time` 并签发业务 token。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "token": "jwt_access_token",
    "user": {
      "id": 1,
      "nickname": null,
      "avatarUrl": null,
      "role": "USER",
      "authStatus": "UNVERIFIED",
      "accountStatus": "NORMAL",
      "lastLoginTime": "2026-06-09T12:00:00+08:00"
    }
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

前端保存 `data.token`，后续请求加：

```http
Authorization: Bearer jwt_access_token
```

## 4. 注销账号登录响应

如果 openid 命中已注销账号，即 `accountStatus=CANCELED` 或 `is_deleted=1`，后端不会返回业务 token，而是返回恢复凭证：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "reactivationToken": "jwt_reactivation_token",
    "requiresReactivation": true,
    "user": {
      "id": 1,
      "nickname": "张三",
      "avatarUrl": "/uploads/avatar/a.png",
      "role": "USER",
      "authStatus": "VERIFIED",
      "accountStatus": "CANCELED"
    }
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

前端处理建议：

- 不要保存 `reactivationToken` 为登录 token。
- 展示“账号已注销，是否恢复账号”的二次确认。
- 用户确认后调用 `POST /auth/reactivate`。
- 用户取消时清理该临时凭证。

## 5. 错误响应

| 场景 | HTTP | code | 说明 |
| --- | ---: | ---: | --- |
| 请求体缺少 `code` | 400 | 400 | Gin 参数绑定失败 |
| `code` 为空字符串 | 400 | 400 | service trim 后校验失败 |
| `code` 超过 128 字符 | 400 | 400 | 长度校验失败 |
| 微信配置缺失 | 500 | 500 | `wechat.app_id` 或 `wechat.app_secret` 未配置 |
| 微信 code2session 失败 | 500 | 500 | 微信返回错误或网络异常 |

错误示例：

```json
{
  "code": 400,
  "message": "微信登录 code 不能为空",
  "data": null,
  "timestamp": "2026-06-09 12:00:00"
}
```
