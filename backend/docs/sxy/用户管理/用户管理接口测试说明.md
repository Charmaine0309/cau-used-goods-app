# 用户管理接口测试说明

## 1. 测试目标

验证管理员用户管理接口是否能完成用户查询、用户详情聚合、账号状态变更、角色变更、学生认证审核和用户关联业务记录查询。

## 2. 测试前准备

确认本地数据库已执行最新建表脚本：

```powershell
cd D:\project2026\软件工程\cau-used-goods-app\backend
mysql -h 127.0.0.1 -P 3308 -u cau -p cau_used_goods < .\scripts\sql\schema.sql
```

如果当前终端的 `mysql` 仍指向旧版本客户端，可改用 MySQL 8 客户端完整路径执行。

启动后端：

```powershell
cd D:\project2026\软件工程\cau-used-goods-app\backend
go run .\cmd\server
```

开发环境生成管理员 token：

```powershell
$baseUrl = "http://127.0.0.1:8080"
$admin = Invoke-RestMethod `
  -Method POST `
  -Uri "$baseUrl/auth/dev-login" `
  -ContentType "application/json" `
  -Body '{"openid":"dev_admin_user_manage","role":"ADMIN"}'

$adminToken = $admin.data.token
```

生成普通用户 token：

```powershell
$user = Invoke-RestMethod `
  -Method POST `
  -Uri "$baseUrl/auth/dev-login" `
  -ContentType "application/json" `
  -Body '{"openid":"dev_user_manage_target","role":"USER"}'

$userId = $user.data.user.id
```

请求头：

```powershell
$adminHeader = @{ Authorization = "Bearer $adminToken" }
```

如果需要测试角色修改接口，需要准备唯一超级管理员账号。开发环境可在数据库中将指定测试账号设置为 `SUPER_ADMIN` 后重新登录获取 token：

```sql
UPDATE users
SET role = 'SUPER_ADMIN', account_status = 'NORMAL', is_deleted = 0
WHERE openid = 'dev_super_admin_user_manage';
```

```powershell
$superAdmin = Invoke-RestMethod `
  -Method POST `
  -Uri "$baseUrl/auth/dev-login" `
  -ContentType "application/json" `
  -Body '{"openid":"dev_super_admin_user_manage"}'

$superAdminHeader = @{ Authorization = "Bearer $($superAdmin.data.token)" }
```

## 3. 用户列表

```powershell
Invoke-RestMethod `
  -Method GET `
  -Uri "$baseUrl/admin/users?page=1&pageSize=20" `
  -Headers $adminHeader
```

预期：

- 返回 `items`、`total`、`page`、`pageSize`。
- 每个用户包含 `role`、`authStatus`、`accountStatus`。

带筛选：

```powershell
Invoke-RestMethod `
  -Method GET `
  -Uri "$baseUrl/admin/users?role=USER&accountStatus=NORMAL&keyword=dev_user_manage" `
  -Headers $adminHeader
```

## 4. 用户详情

```powershell
Invoke-RestMethod `
  -Method GET `
  -Uri "$baseUrl/admin/users/$userId" `
  -Headers $adminHeader
```

预期返回：

- `user`
- `stats`
- `recentReports`
- `recentAppeals`
- `recentAdminLogs`

## 5. 修改账号状态

禁用用户：

```powershell
Invoke-RestMethod `
  -Method PUT `
  -Uri "$baseUrl/admin/users/$userId/status" `
  -Headers $adminHeader `
  -ContentType "application/json" `
  -Body '{"accountStatus":"DISABLED","reason":"用户管理接口测试禁用"}'
```

恢复用户：

```powershell
Invoke-RestMethod `
  -Method PUT `
  -Uri "$baseUrl/admin/users/$userId/status" `
  -Headers $adminHeader `
  -ContentType "application/json" `
  -Body '{"accountStatus":"NORMAL","reason":"用户管理接口测试恢复"}'
```

预期：

- 返回更新后的用户。
- `accountStatus` 正确变化。
- `/admin/users/:id/logs` 中出现对应的用户状态日志，例如 `USER_DISABLE`、`USER_ENABLE`、`USER_BAN` 或 `USER_UNBAN`。

## 6. 修改角色

设置为管理员：

```powershell
Invoke-RestMethod `
  -Method PUT `
  -Uri "$baseUrl/admin/users/$userId/role" `
  -Headers $superAdminHeader `
  -ContentType "application/json" `
  -Body '{"role":"ADMIN","reason":"用户管理接口测试设置管理员"}'
```

恢复为普通用户：

```powershell
Invoke-RestMethod `
  -Method PUT `
  -Uri "$baseUrl/admin/users/$userId/role" `
  -Headers $superAdminHeader `
  -ContentType "application/json" `
  -Body '{"role":"USER","reason":"用户管理接口测试恢复普通用户"}'
```

预期：

- 返回更新后的用户。
- `role` 正确变化。
- `/admin/users/:id/logs` 中出现 `USER_ROLE_CHANGE`。

## 7. 关联业务记录

```powershell
Invoke-RestMethod -Method GET -Uri "$baseUrl/admin/users/$userId/products" -Headers $adminHeader
Invoke-RestMethod -Method GET -Uri "$baseUrl/admin/users/$userId/orders" -Headers $adminHeader
Invoke-RestMethod -Method GET -Uri "$baseUrl/admin/users/$userId/reports" -Headers $adminHeader
Invoke-RestMethod -Method GET -Uri "$baseUrl/admin/users/$userId/appeals" -Headers $adminHeader
Invoke-RestMethod -Method GET -Uri "$baseUrl/admin/users/$userId/reviews" -Headers $adminHeader
Invoke-RestMethod -Method GET -Uri "$baseUrl/admin/users/$userId/logs" -Headers $adminHeader
```

预期：

- 均返回分页结构。
- 无关联数据时 `items` 为空数组，`total=0`。

## 8. 权限测试

普通用户不能访问后台用户管理：

```powershell
$userHeader = @{ Authorization = "Bearer $($user.data.token)" }

Invoke-RestMethod `
  -Method GET `
  -Uri "$baseUrl/admin/users" `
  -Headers $userHeader
```

预期：

```text
HTTP 403
```

## 9. 边界测试

建议覆盖：

- 无 token 访问后台接口，返回 401。
- 普通用户访问后台接口，返回 403。
- 管理员修改自己的账号状态，返回 403。
- 管理员修改自己的角色，返回 403。
- `accountStatus` 非法，返回 400。
- `role` 非法，返回 400。
- `reason` 为空，返回 400。
- 移除最后一个管理员，返回 409。
- 查询不存在用户，返回 404。
