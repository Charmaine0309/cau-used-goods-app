# 用户端资料与账号接口

## 1. 查看当前用户资料

```http
GET /users/me
Authorization: Bearer <token>
```

### 响应

`data` 为当前用户完整资料：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "nickname": "张三",
    "avatarUrl": "/uploads/avatar/a.png",
    "studentId": "20240001",
    "realName": "张三",
    "college": "信息与电气工程学院",
    "phone": "13800000000",
    "role": "USER",
    "authStatus": "VERIFIED",
    "accountStatus": "NORMAL"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

### 前端用途

用于个人中心、登录态恢复、判断是否已认证、判断账号是否受限。

## 2. 查看当前账号限制信息

```http
GET /users/me/restriction
Authorization: Bearer <token>
```

用于受限账号页面展示最近一次封禁/禁用原因。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `accountStatus` | string | 当前账号状态 |
| `reason` | string/null | 最近一次限制原因 |
| `operationType` | string/null | `USER_DISABLE` 或 `USER_BAN` |
| `relatedType` | string/null | `REPORT` / `APPEAL` |
| `relatedId` | number/null | 关联业务 ID |
| `createTime` | string/null | 后台操作时间 |

### 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accountStatus": "DISABLED",
    "reason": "违规交易",
    "operationType": "USER_DISABLE",
    "relatedType": "REPORT",
    "relatedId": 12,
    "createTime": "2026-06-09 12:00:00"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

如果账号不是 `DISABLED` 或 `BANNED`，通常只返回 `accountStatus`。

## 3. 查看公开用户资料

```http
GET /users/{id}/public
Authorization: Bearer <token>
```

### 路径参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | number | 是 | 目标用户 ID，必须大于 0 |

### 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 2,
    "nickname": "李四",
    "avatarUrl": "/uploads/avatar/b.png",
    "authStatus": "VERIFIED",
    "tradeAvailable": true
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

### 规则

- 只返回 `NORMAL` 和 `DISABLED` 且未删除用户的公开资料。
- `tradeAvailable=true` 表示目标用户账号为 `NORMAL`。
- `BANNED`、`CANCELED` 或不存在的用户返回 404。
- 不返回手机号、学号、真实姓名、openid、角色、账号状态。

## 4. 修改个人资料

```http
PUT /users/profile
Authorization: Bearer <token>
Content-Type: application/json
```

该接口要求当前账号为 `NORMAL`。

### 请求参数

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `nickname` | string | 否 | trim 后 1-50 字符 |
| `avatarUrl` | string | 否 | http(s) URL 或 `/uploads/avatar/` 路径，最长 255 字符 |
| `phone` | string | 否 | 必须匹配 `^1[3-9]\d{9}$` |

至少传一个字段。

请求示例：

```json
{
  "nickname": "张三",
  "avatarUrl": "https://example.com/avatar.jpg",
  "phone": "13800000000"
}
```

### 头像 URL 处理

- 如果 `avatarUrl` 是 `/uploads/avatar/...`，后端直接保存。
- 如果是 http(s) URL，后端会下载图片并转存到 `uploads/avatar`。
- 下载文件最大 2MB，支持 jpeg/png/webp。
- 最终写入数据库的是 `/uploads/avatar/文件名`。

### 响应

`data` 为更新后的用户资料，结构同 `/users/me`。

## 5. 上传头像

```http
POST /users/avatar
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

该接口要求当前账号为 `NORMAL`。

### 表单字段

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `avatar` | file | 是 | 最大 2MB；扩展名 `.jpg` / `.jpeg` / `.png` / `.webp` |

### 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "avatarUrl": "/uploads/avatar/05c6bbed505fad7e8be0b30b1492bb75.jpg",
    "user": {
      "id": 1,
      "nickname": "张三",
      "avatarUrl": "/uploads/avatar/05c6bbed505fad7e8be0b30b1492bb75.jpg",
      "studentId": null,
      "realName": null,
      "college": null,
      "phone": "13800000000",
      "role": "USER",
      "authStatus": "UNVERIFIED",
      "accountStatus": "NORMAL"
    }
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

前端展示图片时用后端域名拼接 `avatarUrl`。

## 6. 主动注销账号

```http
POST /users/cancel
Authorization: Bearer <token>
Content-Type: application/json
```

该接口要求当前账号为 `NORMAL`，且只能普通用户主动注销。

### 请求参数

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `confirm` | boolean | 是 | 必须为 `true` |

请求示例：

```json
{
  "confirm": true
}
```

### 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accountStatus": "CANCELED"
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

### 业务规则

- `role=USER` 才能主动注销。
- `ADMIN` 需要先由超级管理员降级为 `USER`。
- 注销前不能存在 `PENDING_CONFIRM` 或 `WAIT_MEET` 订单。
- 注销时自动下架在售商品。
- 注销后 `account_status=CANCELED`、`is_deleted=1`、`token_version+1`。
- 前端应立即清理本地 token 和用户缓存。

## 7. 常见错误

| 场景 | HTTP | code |
| --- | ---: | ---: |
| 未登录或 token 无效 | 401 | 401 |
| 当前账号已注销 | 403 | 403 |
| 当前账号不是 NORMAL 但执行写操作 | 403 | 403 |
| 路径 id 非法 | 400 | 400 |
| 不存在公开资料 | 404 | 404 |
| 修改资料未传任何字段 | 400 | 400 |
| 手机号格式错误 | 400 | 400 |
| 头像文件缺失、过大或格式不支持 | 400 | 400 |
| 注销时未确认 | 400 或 409 | 取决于错误映射分支 |
| 存在进行中订单，不能注销 | 409 | 409 |
