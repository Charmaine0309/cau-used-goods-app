# 后台用户管理接口

## 1. 用户列表

```http
GET /admin/users?keyword=张三&authStatus=VERIFIED&accountStatus=NORMAL&role=USER&page=1&pageSize=20
Authorization: Bearer <admin_token>
```

需要 `ADMIN` 或 `SUPER_ADMIN`。

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 模糊搜索昵称、学号、真实姓名、手机号；超级管理员还会搜索 openid |
| `authStatus` | string | 否 | `UNVERIFIED` / `PENDING` / `VERIFIED` / `REJECTED` |
| `accountStatus` | string | 否 | `NORMAL` / `DISABLED` / `BANNED` / `CANCELED` |
| `role` | string | 否 | `USER` / `ADMIN` / `SUPER_ADMIN` |
| `page` | number | 否 | 默认 1 |
| `pageSize` | number | 否 | 默认 20，最大 100 |

说明：不传 `accountStatus` 时，默认排除 `CANCELED` 用户；需要查询注销用户时显式传 `accountStatus=CANCELED`。

### 响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 1,
        "nickname": "张三",
        "avatarUrl": "/uploads/avatar/a.png",
        "studentId": "20240001",
        "realName": "张三",
        "college": "信息与电气工程学院",
        "phone": "13800000000",
        "role": "USER",
        "authStatus": "VERIFIED",
        "accountStatus": "NORMAL",
        "lastLoginTime": "2026-06-09 12:00:00",
        "createTime": "2026-06-01 10:00:00",
        "updateTime": "2026-06-09 12:00:00",
        "isDeleted": false
      }
    ],
    "total": 1,
    "page": 1,
    "pageSize": 20
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

普通管理员返回中 `openid` 不可见；超级管理员可见。

## 2. 用户详情聚合视图

```http
GET /admin/users/{id}
Authorization: Bearer <admin_token>
```

需要 `ADMIN` 或 `SUPER_ADMIN`。

### 响应结构

| 字段 | 说明 |
| --- | --- |
| `user` | 后台用户资料 |
| `stats` | 用户统计 |
| `recentReports` | 最近 5 条举报记录 |
| `recentAppeals` | 最近 5 条申诉记录 |
| `recentAdminLogs` | 最近 5 条用户管理日志 |

### 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "user": {
      "id": 1,
      "nickname": "张三",
      "role": "USER",
      "authStatus": "VERIFIED",
      "accountStatus": "NORMAL",
      "createTime": "2026-06-01 10:00:00",
      "updateTime": "2026-06-09 12:00:00",
      "isDeleted": false
    },
    "stats": {
      "productCount": 3,
      "onSaleProductCount": 1,
      "orderCount": 2,
      "completedOrderCount": 1,
      "reportSubmittedCount": 0,
      "reportedCount": 1,
      "appealCount": 0,
      "reviewGivenCount": 1,
      "reviewReceivedCount": 1,
      "adminOperationCount": 2
    },
    "recentReports": [],
    "recentAppeals": [],
    "recentAdminLogs": []
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

普通管理员看不到 `openid`，并且日志 `ipAddress` 会被隐藏；超级管理员可见。

## 3. 修改账号状态

```http
PUT /admin/users/{id}/status
Authorization: Bearer <admin_token>
Content-Type: application/json
```

需要 `ADMIN` 或 `SUPER_ADMIN`。

### 请求参数

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `accountStatus` | string | 是 | 只能为 `NORMAL` / `DISABLED` / `BANNED` |
| `reason` | string | 是 | trim 后必填，不超过 500 字符 |
| `relatedType` | string | 否 | `REPORT` / `APPEAL` |
| `relatedId` | number | 否 | 与 `relatedType` 同时传或同时不传 |

禁用示例：

```json
{
  "accountStatus": "DISABLED",
  "reason": "违规交易",
  "relatedType": "REPORT",
  "relatedId": 12
}
```

恢复封禁示例：

```json
{
  "accountStatus": "NORMAL",
  "reason": "申诉通过",
  "relatedType": "APPEAL",
  "relatedId": 8
}
```

### 成功响应

`data` 为更新后的后台用户资料。

### 状态流转规则

```text
NORMAL   -> DISABLED
NORMAL   -> BANNED
DISABLED -> NORMAL
DISABLED -> BANNED
BANNED   -> NORMAL（仅 SUPER_ADMIN，且必须关联已通过申诉）
```

禁止：

- 管理员修改自己的账号状态。
- 修改超级管理员账号状态。
- 普通管理员修改管理员账号状态。
- 对 `CANCELED` 用户执行后台状态变更。
- 任意跳转到未声明的状态。

### 副作用

变更为 `DISABLED` 或 `BANNED` 时：

- 存在待面交订单会拒绝操作。
- 待确认订单会自动异常关闭。
- 该用户在售商品会自动下架。
- 写入后台日志并发送系统消息。

## 4. 修改角色

```http
PUT /admin/users/{id}/role
Authorization: Bearer <super_admin_token>
Content-Type: application/json
```

只允许 `SUPER_ADMIN`。

### 请求参数

| 字段 | 类型 | 必填 | 规则 |
| --- | --- | --- | --- |
| `role` | string | 是 | 只能为 `USER` 或 `ADMIN` |
| `reason` | string | 是 | trim 后必填，不超过 500 字符 |

请求示例：

```json
{
  "role": "ADMIN",
  "reason": "任命为平台管理员"
}
```

### 成功响应

`data` 为更新后的后台用户资料。

### 规则

- 超级管理员不能修改自己的角色。
- 目标账号必须存在、未删除且 `accountStatus=NORMAL`。
- 不能通过接口设置或修改 `SUPER_ADMIN`。
- 目标用户已经是该角色时返回业务冲突。
- 操作写入 `admin_logs`，操作类型为 `USER_ROLE_CHANGE`。

## 5. 常见错误

| 场景 | HTTP | code |
| --- | ---: | ---: |
| 未登录 | 401 | 401 |
| 非管理员访问后台接口 | 403 | 403 |
| 非超级管理员修改角色 | 403 | 403 |
| 用户 ID 非法 | 400 | 400 |
| 用户不存在 | 404 | 404 |
| 查询参数枚举非法 | 400 | 400 |
| 状态流转不允许 | 409 | 409 |
| 管理员修改自己 | 403 | 403 |
| 普通管理员修改管理员账号 | 403 | 403 |
| 撤销永久封禁未关联通过的申诉 | 409 | 409 |
| `relatedType` 与 `relatedId` 只传一个 | 400 | 400 |
| 目标角色非法或重复 | 400 或 409 | 取决于错误分支 |
