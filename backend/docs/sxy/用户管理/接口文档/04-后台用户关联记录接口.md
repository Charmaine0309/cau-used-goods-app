# 后台用户关联记录接口

本文档覆盖 `/admin/users/{id}/products`、`orders`、`reports`、`appeals`、`reviews`、`logs`。所有接口都需要 `ADMIN` 或 `SUPER_ADMIN`。

通用路径参数：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | number | 是 | 目标用户 ID，必须大于 0 |

通用分页参数：

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `page` | number | 1 | 页码 |
| `pageSize` | number | 20 | 每页数量，最大 100 |

所有接口在查询关联记录前都会确认目标用户存在。

## 1. 用户商品记录

```http
GET /admin/users/{id}/products?page=1&pageSize=20&dataScope=ACTIVE
Authorization: Bearer <admin_token>
```

### 查询参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `dataScope` | string | 否 | `ACTIVE` | `ACTIVE` 仅未删除，`DELETED` 仅删除，`ALL` 全部 |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 商品 ID |
| `title` | string | 商品标题 |
| `price` | number | 商品价格 |
| `status` | string | 商品状态 |
| `viewCount` | number | 浏览数 |
| `favoriteCount` | number | 收藏数 |
| `createTime` | string | 创建时间 |
| `imageUrl` | string/null | 首图 |

### 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 10,
        "title": "二手教材",
        "price": 20,
        "status": "ON_SALE",
        "viewCount": 15,
        "favoriteCount": 2,
        "createTime": "2026-06-09 12:00:00",
        "imageUrl": "/uploads/products/a.jpg"
      }
    ],
    "total": 1,
    "page": 1,
    "pageSize": 20
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 2. 用户订单记录

```http
GET /admin/users/{id}/orders?page=1&pageSize=20
Authorization: Bearer <admin_token>
```

返回用户作为买家或卖家的订单。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 订单 ID |
| `orderNo` | string | 订单编号 |
| `productId` | number | 商品 ID |
| `productTitleSnapshot` | string | 下单时商品标题 |
| `productPriceSnapshot` | number | 下单时商品价格 |
| `buyerId` | number | 买家 ID |
| `buyerNickname` | string/null | 买家昵称 |
| `sellerId` | number | 卖家 ID |
| `sellerNickname` | string/null | 卖家昵称 |
| `status` | string | 订单状态 |
| `createTime` | string | 创建时间 |
| `updateTime` | string | 更新时间 |

## 3. 用户举报记录

```http
GET /admin/users/{id}/reports?page=1&pageSize=20
Authorization: Bearer <admin_token>
```

返回用户提交的举报，以及目标为该用户的举报。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 举报 ID |
| `relation` | string | `SUBMITTED` 表示该用户提交；`REPORTED` 表示该用户被举报 |
| `reporterId` | number | 举报人 ID |
| `reporterNickname` | string/null | 举报人昵称 |
| `targetType` | string | 举报目标类型 |
| `targetId` | number | 举报目标 ID |
| `reasonType` | string | 举报原因类型 |
| `status` | string | 举报状态 |
| `handleResult` | string/null | 处理结果 |
| `createTime` | string | 创建时间 |
| `updateTime` | string | 更新时间 |

## 4. 用户申诉记录

```http
GET /admin/users/{id}/appeals?page=1&pageSize=20
Authorization: Bearer <admin_token>
```

返回用户提交的申诉，以及目标为该用户的申诉。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 申诉 ID |
| `relation` | string | `SUBMITTED` 表示该用户提交；`TARGET` 表示该用户为申诉目标 |
| `appellantId` | number | 申诉人 ID |
| `appellantNickname` | string/null | 申诉人昵称 |
| `targetType` | string | 目标类型 |
| `targetId` | number | 目标 ID |
| `reason` | string | 申诉理由 |
| `status` | string | 申诉状态 |
| `handleResult` | string/null | 处理结果 |
| `createTime` | string | 创建时间 |
| `updateTime` | string | 更新时间 |

说明：如果 `appeals` 表不存在，当前实现会返回空列表而不是报错。

## 5. 用户评价记录

```http
GET /admin/users/{id}/reviews?page=1&pageSize=20&dataScope=ACTIVE
Authorization: Bearer <admin_token>
```

返回用户发出的评价和收到的评价。

### 查询参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `dataScope` | string | 否 | `ACTIVE` | `ACTIVE` 仅未删除，`DELETED` 仅删除，`ALL` 全部 |

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 评价 ID |
| `relation` | string | `GIVEN` 发出的评价；`RECEIVED` 收到的评价 |
| `orderId` | number | 订单 ID |
| `productId` | number | 商品 ID |
| `productTitle` | string | 商品标题 |
| `reviewerId` | number | 评价人 ID |
| `reviewerNickname` | string/null | 评价人昵称 |
| `sellerId` | number | 卖家 ID |
| `sellerNickname` | string/null | 卖家昵称 |
| `rating` | number | 评分 |
| `content` | string/null | 评价内容 |
| `status` | string | 评价状态 |
| `createTime` | string | 创建时间 |

## 6. 用户管理日志

```http
GET /admin/users/{id}/logs?page=1&pageSize=20
Authorization: Bearer <admin_token>
```

返回 `target_type='USER'` 且 `target_id={id}` 的后台操作日志。

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 日志 ID |
| `adminId` | number | 操作管理员 ID |
| `adminNickname` | string/null | 管理员昵称 |
| `operationType` | string | 操作类型 |
| `targetType` | string | 固定为 `USER` |
| `targetId` | number | 目标用户 ID |
| `description` | string/null | 操作说明 |
| `ipAddress` | string/null | 超级管理员可见；普通管理员会被置空 |
| `relatedType` | string/null | 关联来源类型 |
| `relatedId` | number/null | 关联来源 ID |
| `createTime` | string | 创建时间 |

### 响应示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 100,
        "adminId": 2,
        "adminNickname": "管理员",
        "operationType": "USER_DISABLE",
        "targetType": "USER",
        "targetId": 1,
        "description": "违规交易",
        "ipAddress": null,
        "relatedType": "REPORT",
        "relatedId": 12,
        "createTime": "2026-06-09 12:00:00"
      }
    ],
    "total": 1,
    "page": 1,
    "pageSize": 20
  },
  "timestamp": "2026-06-09 12:00:00"
}
```

## 7. 常见错误

| 场景 | HTTP | code |
| --- | ---: | ---: |
| 未登录 | 401 | 401 |
| 非管理员访问 | 403 | 403 |
| 用户 ID 非法 | 400 | 400 |
| 目标用户不存在 | 404 | 404 |
| `dataScope` 非法 | 400 | 400 |
| 数据库查询异常 | 500 | 500 |
