# 用户管理接口通用约定

## 1. Base URL

后端没有全局 `/api` 前缀。本地默认：

```text
http://127.0.0.1:8080
```

示例：

```text
GET http://127.0.0.1:8080/users/me
```

## 2. 鉴权

本文档所有 `/users` 和 `/admin/users` 接口都需要登录：

```http
Authorization: Bearer <token>
```

管理员接口还要求当前用户在数据库中仍满足：

```text
role = ADMIN 或 SUPER_ADMIN
account_status = NORMAL
is_deleted = 0
```

超级管理员接口要求：

```text
role = SUPER_ADMIN
account_status = NORMAL
is_deleted = 0
```

## 3. 统一响应

成功：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "timestamp": "2026-06-09 12:00:00"
}
```

失败：

```json
{
  "code": 403,
  "message": "当前账号状态不可操作",
  "data": null,
  "timestamp": "2026-06-09 12:00:00"
}
```

## 4. 分页约定

后台列表类接口使用：

| 参数 | 类型 | 默认 | 规则 |
| --- | --- | --- | --- |
| `page` | number | 1 | 小于 1 时按 1 处理 |
| `pageSize` | number | 20 | 小于 1 时按 20，最大 100 |

分页响应：

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "pageSize": 20
}
```

## 5. 枚举

账号状态：

```text
NORMAL / DISABLED / BANNED / CANCELED
```

学生认证状态：

```text
UNVERIFIED / PENDING / VERIFIED / REJECTED
```

角色：

```text
USER / ADMIN / SUPER_ADMIN
```

关联来源：

```text
REPORT / APPEAL
```

数据范围：

```text
ACTIVE / DELETED / ALL
```

## 6. 用户对象

用户端 `User`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | number | 用户 ID |
| `nickname` | string/null | 昵称 |
| `avatarUrl` | string/null | 头像 URL |
| `studentId` | string/null | 学号 |
| `realName` | string/null | 真实姓名 |
| `college` | string/null | 学院 |
| `phone` | string/null | 手机号 |
| `role` | string | 用户角色 |
| `authStatus` | string | 学生认证状态 |
| `accountStatus` | string | 账号状态 |

后台 `AdminUser` 在 `User` 基础上额外返回：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `openid` | string/null | 仅超级管理员可见；普通管理员返回时会被置空或省略 |
| `lastLoginTime` | string/null | 最近登录时间 |
| `createTime` | string | 创建时间 |
| `updateTime` | string | 更新时间 |
| `isDeleted` | boolean | 是否逻辑删除 |

## 7. 前端错误处理建议

- `401`：清理登录态并跳转登录页。
- `403`：展示权限或账号状态提示，不要重试。
- `409`：展示业务冲突提示，例如重复提交、状态已变化、存在进行中订单。
- `500`：展示系统异常提示，并记录接口与请求参数方便排查。
