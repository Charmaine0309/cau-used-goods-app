# 交易与互动流模块说明

本模块基于：frontend/cau-used-goods-uni源码实现。`unpackage` 为编译产物，不应作为主要修改目录，也不包含在个人提交包中。

## 实现范围

- 提交预约、买家/卖家订单列表、订单详情、确认、取消、完成。
- 收藏列表、收藏商品、取消收藏。
- 消息中心、消息详情、标记已读、关联订单跳转。
- 已完成订单评价。
- 商品/订单举报、凭证图片上传、我的举报记录。

## 必要接入改动

- `App.vue`：加载交易模块公共样式。
- `pages.json`：登记交易互动页面。
- `utils/request.js`：增加举报凭证图片上传封装。
- `pages/detail/detail.vue`：接通收藏、预约和举报入口。
- `pages/index/index.vue`：增加订单、收藏、消息和举报入口。

## 后端接口

- 订单：`/orders`
- 收藏：`/favorites`
- 消息：`/messages`
- 评价：`/reviews`
- 举报：`/reports`
- 图片上传：`/upload/image`

## 后端待补项

1. 订单详情当前没有返回联系方式字段，待面交阶段只能展示提示。
2. 订单状态变化暂未自动写入站内消息。
3. `GET /reports/:id` 仍需确认是否限制为举报人或管理员查看。
4. `/admin/orders/cleanup-expired` 当前仍建议增加管理员中间件。
